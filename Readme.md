## 概要

AirFriendsは、ゼミ活動内で開発中の「環境センサIoT」デバイスです。
M5Stack Core2をプラットフォームとして採用し、温湿度、気圧、二酸化炭素濃度を計測・記録し、適切な室内環境を維持するサポートを目的としています。

当リポジトリは、「ESP32 Devkit V2」にて開発していた[旧リポジトリ(Private)](https://github.com/Koranoa3/AirFriends) からの移行版となります。
移行理由：表示・操作などのインターフェースに関する自作/導入ライブラリがCore2用ライブラリに置き換わり、当時時点での開発コードの多くが流用できなくなったため。

## 機能(順次実装予定)

- 温度、湿度、気圧、二酸化炭素濃度の計測
- 計測データのSDカードへの保存
- Wi-Fi経由でのクラウドサーバへのデータ送信
- M5Stack Core2のスクリーンを用いた操作・表示
- 適性環境パーソナライズ

## ハードウェア構成
- M5Stack Core2
- BME680 (温湿度,気圧,ガスセンサ)
- TGS8100 (ガスセンサ)

SD, Speaker, TouchScreen, Button等はM5Stack Core2に内蔵。素晴らしい...しかもバッテリー内臓ときた。

## 環境構築

1. PlatformIOをインストール(VSCode拡張機能)
